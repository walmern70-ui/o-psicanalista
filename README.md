# O Psicanalista — projeto inicial

Protótipo de site em Next.js com interface de conversa e integração no servidor com a API da OpenAI.

## Configuração
- Node.js LTS
- Chave de API OpenAI e modelo habilitado
- Defina OPENAI_API_KEY e OPENAI_MODEL nas variáveis de ambiente do servidor.
- Instale dependências com npm install e execute npm run dev.

## Segurança e lançamento
A chave da API deve permanecer somente no servidor. Antes de comercializar, integrar autenticação, limites de uso, monitoramento de custos, pagamentos com confirmação por webhook, política de retenção e exclusão de dados, revisão jurídica de privacidade/termos e testes de segurança.

O assistente é educativo e informativo. Não realiza diagnóstico, psicoterapia ou atendimento de emergência e não substitui profissionais humanos.
